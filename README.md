# أرشيف الباحثة الذكية

مستودع خاص لحفظ وفهرسة الأحكام والصكوك والتعاميم والقرارات والمدونات القضائية المستخدمة في منصة الباحثة القانونية الذكية.

## قواعد إلزامية

- حفظ كل ملف أصلي دون تغيير.
- فصل كل حكم أو قضية أو تعميم أو قرار إلى سجل مستقل.
- عدم احتساب المدونة أو الفهرس كحكم.
- منع التكرار ببصمة SHA-256 ثم بمقارنة المرجع والمحتوى.
- حفظ جميع أسماء ومصادر النسخ المكررة في سجل التكرارات.
- عدم حذف أي أصل قبل إثبات التطابق وتعيين النسخة الأصلية المعتمدة.
- عرض النوع القانوني الحقيقي: حكم، صك، تعميم، قرار، مدونة، مبدأ أو سابقة قضائية.
- الاحتفاظ بمرجع الصفحات والملف الأصلي لكل سجل مفصول.

## المصادر المعتمدة

1. ملفات الأرشيف المرفوعة.
2. المصادر الرسمية لوزارة العدل والجهات القضائية.
3. قناة الأرشيف العامة في Telegram مع حفظ رابط المنشور والمصدر.
4. المصادر الرسمية أو الموثوقة الأخرى بعد توثيقها.

## بنية السجلات

- `manifests/source-register.csv`: جميع الملفات والمصادر.
- `manifests/duplicate-register.csv`: النسخ المكررة وسبب استبعادها من العد.
- `manifests/processing-log.csv`: حالة الفصل والفهرسة.
- `docs/ARCHIVE_POLICY.md`: سياسة الحفظ والمصداقية.
